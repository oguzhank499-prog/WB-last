# WB 1.4 — Bilimsel doğruluk beta

WB 1.3 üzerine geliştirildi. İlerleme verileri korunacak şekilde mevcut yerel kayıt anahtarları değiştirilmedi. Kuvvetli tek protonlu asit / tek hidroksitli baz pH hesaplayıcısı, 25 °C'de suyun otoiyonlaşmasını da içerecek şekilde düzeltildi.

Denetim için `node audit-ph-14.js`, `node verify.js`, `node verify5.js`, `node audit-chemistry.js`, `node audit-science-12.js`, `node audit-manual-13.js` çalıştırılabilir.

Bu beta paketini mevcut çalışan uygulamanın üzerine yüklemeden önce ilerleme yedeği alın. Ayrıntılar: README-VALIDATION.md.
