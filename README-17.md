# WB 1.7 — Yanlış defteri iyileştirmesi

WB 1.6'nın bütün özellikleri korunmuştur.

- Yeni yanlış cevaplarda soru metni, doğru cevap, açıklama ve konu yerel olarak kaydedilir.
- Yanlış defterinde soru ve cevaplar açılır/kapanır biçimde görünür.
- 'Tekrar oyununa git' doğrudan Tekrar modunu başlatır.
- Kayıtlar 250 farklı soruyla sınırlandırılır; internet bağlantısı gerekmez.
- `kimyalab-state` ilerleme anahtarı korunur.

## Sınırlar
Önceden kaydedilen yanlışlarda soru metni bulunmadığından geri oluşturulamaz. Bu güncelleme soru bankasının akademik doğrulaması veya gerçek Android cihaz testi değildir.
