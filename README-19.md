# WB 1.9 — Çevrimdışı durum ve yedek kontrolü

WB 1.8 üzerine geliştirilmiştir.

- Çevrimdışı durum göstergesi artık eski v8 önbelleğine değil güncel v22 önbelleğine bakar.
- Gösterge bütün çekirdek JS modüllerini kontrol eder.
- Yedek içe aktarımına dosya boyutu ve ilerleme sayacı kontrolleri eklendi.
- Yedekteki tercih alanları yalnızca izin verilen tema, hareket ve dil anahtarlarına indirgenir.
- Önceki özellikler korunmuştur.
